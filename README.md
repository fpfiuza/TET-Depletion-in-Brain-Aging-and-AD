# TET-Depletion-in-Brain-Aging-and-AD
Contains Fiji-ImageJ macros and python scripts for analysis of multiplex immunofluorescence images and snRNAseq databases. Accompanies the manuscript by Escariao et al. 
This repository is organized topically based on our manuscript. There is a different subfolder for each type of analysis. 
The Fiji macro was executed in a Fiji software version 1.54p, with the PTBIOP extension and JACoP plugin version 1.3.0. 
The Python scripts were executed within a Conda environment using the packages listed below:
